# ChatGPT への引き継ぎ手順

## このフォルダの中身

| ファイル | 使い方 |
|---|---|
| `01_カスタム指示用.md` | ChatGPT の「設定 → パーソナライズ → カスタム指示」に貼る短い版（各欄1,500字以内） |
| `02_全記録_一括貼り付け用.md` | 新しいチャットの最初にまるごと貼る長い版。これまでの話し合い・決定・プロジェクトを全部まとめたもの |
| `02_全記録_一括貼り付け用.docx` | 上と同じ内容の Word 版（ChatGPT にファイルとして添付してもよい） |

## 手順（5分）

1. **カスタム指示を設定する**
   ChatGPT → 左下の名前 → 設定 → パーソナライズ → カスタム指示。
   `01_カスタム指示用.md` の「欄1」「欄2」をそれぞれコピーして貼る。
2. **全記録を渡す**
   新しいチャットを開き、`02_全記録_一括貼り付け用.md` の中身を全部コピーして貼り、送信する。
   （長すぎて送れないときは、Word 版 `.docx` を添付して「この内容を覚えて」と送る）
3. **メモリに保存させる**
   ChatGPT の返事のあとに「この内容の重要な部分をメモリに保存して」と送る。
   設定 → パーソナライズ → メモリ で保存されたかを確認できる。
4. **プロジェクト機能を使う場合（おすすめ）**
   ChatGPT の「プロジェクト」を1つ作り（例: 小澤の外部脳）、`.docx` をプロジェクトのファイルに入れておくと、毎回貼らなくても参照してくれる。

## 注意

- 株のポートフォリオ（保有銘柄・損益）は 2026-05-27 時点の数字です。
- API キーやパスワードは入れていません。ChatGPT に貼らないでください。
- ChatGPT は Obsidian・GitHub・GitHub Actions を直接操作できません（後半の「ChatGPT でできないこと」参照）。
